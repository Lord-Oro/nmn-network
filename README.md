# ⛏ Nonsense Media Network (NMN)

**"The mine is not a metaphor. The mine is the thing itself."**

Welcome to the core infrastructure of the Nonsense Media Network. This repository houses the front-end architecture, HTML5 canvas games, procedural soundscapes, and virtual economy that make up Lord Oro's transmedia universe.

## ⬡ The V2 Architecture

The mine operates on a robust, memory-safe, and interconnected ecosystem:

* **`nmn-wallet.js`**: The V2 Global Economy. Securely tracks Gold, Gems, XP, and Scholar Rank across all tunnels, ensuring players are rewarded for their descent.
* **`nmn-scene.js`**: The central canvas scene manager. Handles render loops, dynamic difficulty scaling, and strict garbage collection to prevent memory leaks during gameplay.
* **`nmn-nav.js`**: Global navigation, dynamic SVG lantern cursor, DOM mutation observers, and the localization framework.
* **`nmn-theme.css`**: The Master Lock. Contains the CRT scanline overlays, gold-threaded UI components, and global aesthetic rules.

## 🔮 The Chambers & Tunnels

The network is divided into several explorable zones:

* **The Recreation Hall (`games.html`)**: The arcade hub housing interconnected canvas games like *The Collector*, *Ore Breaker*, *Weaver's Loom*, and *Ore Racer*.
* **The Oracle's Chamber (`oracle.html`)**: The esoteric center featuring Tora's tarot readings, *The Echoing Well* (bibliomancy), and *The Vigil*.
* **The Sacred Archives (`lorevault.html` & `grimoire.html`)**: The permanent, player-specific record of unlocked story fragments, transmissions, and historical cat lore.
* **The Projection Room (`shorts.html`)**: Cinematic trailers, AI-generated shorts, and character broadcasts in a 9:16 format.
* **Ivy's Gem Shop (`gemshop.html`)**: The progression sink where players spend their mined Gold on exclusive lore, short story PDFs, and Star Map placements.

## 🎙️ Procedural Audio

The network features a zero-dependency, procedural quad-track audio engine generated purely through the Web Audio API (`AudioContext`). It simulates the ambient breathing, wind, distant pickaxe strikes, and subterranean water drips of a living goldmine.
